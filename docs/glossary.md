# Glossary

Quick lookup for current Nefor terminology. Process behavior is specified in the [NCP reference](reference/ncp.md); the longer live implementation account remains [`protocol.md`](protocol.md).

| Term                       | Definition                                                                                                                                                                             | Primary reference                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| **Actor artifact**         | Compiled MAG data describing a concrete typed graph for a fresh run. It crosses the evaluator/host/kernel boundary rather than exposing live kernel tables.                            | `plugins/mag/docs/ir.md`                     |
| **Approval request/reply** | A qualified term: either starter tool/plan permission traffic or MAG human-node messages. These are separate systems.                                                                  | [`user/permissions.md`](user/permissions.md) |
| **Body**                   | Content object inside a system/event line. NCP handles system bodies; event bodies belong to layered protocols.                                                                        | [`reference/ncp.md`](reference/ncp.md)       |
| **Broker**                 | Engine transport layer that attaches subprocesses, records raw published entries in an in-memory log, and invokes Lua dispatch. Parsed NCP envelope semantics are Lua-owned.           | `engine/src/ncp/`                            |
| **Bus**                    | Append-only publication history plus Lua-controlled delivery. Publication does not imply every peer receives an entry: wrappers, targets, self-skip, and prefix routing may narrow it. | [`protocol.md`](protocol.md)                 |
| **Engine**                 | The `nefor` binary: process spawner, raw line router, Lua host, and in-memory dispatch-log owner. It is session-blind and has no provider/persona/UI policy.                           | `engine/README.md`                           |
| **Envelope**               | Canonical authored `{type, body}` or delivered `{type, from, ts, body}` JSON object. Lua currently tolerates authored `from` only as compatibility behavior.                           | [`reference/ncp.md`](reference/ncp.md)       |
| **Event**                  | A line with `type: event`; its object body is opaque to the Rust engine and interpreted by Lua/plugins.                                                                                | [`protocol.md`](protocol.md)                 |
| **Factory**                | A MAG kernel constructor and declared contract used for lazy run-scoped actor creation. The shipped factory registry is an implementation API, not a third-party plugin interface.     | `plugins/mag/docs/actor-model.md`            |
| **Graph delta**            | `nefor.graph-delta/v1` data representing a validated operational graph change. Distinct from direct mutation of a live graph definition.                                               | `plugins/mag/docs/ir.md`                     |
| **Graph modification**     | `nefor.graph-modification/v1` data produced at the MAG evaluator/host boundary before validated application.                                                                           | `plugins/mag/docs/ir.md`                     |
| **Kind**                   | Discriminator inside `body` identifying a message sub-shape. System kinds are NCP-owned; event kinds belong to ecosystem protocols.                                                    | [`reference/ncp.md`](reference/ncp.md)       |
| **Lua actor**              | Composition-local `{name, receive_msg}` value dispatched in registration order by `core.actor`. It is not a process and performs no NCP handshake.                                     | `lua/core/actor.lua`                         |
| **MAG actor**              | Run-scoped in-memory actor managed by the MAG kernel. It communicates on typed graph edges and is unaware of the engine bus.                                                           | `plugins/mag/docs/actor-model.md`            |
| **Manifest event**         | Optional ecosystem convention advertising plugin version and accepted/emitted event kinds. NCP does not validate it.                                                                   | [`plugin-authoring.md`](plugin-authoring.md) |
| **NCP**                    | Current subprocess composition behavior implemented by engine transport plus `lua/core/ncp.lua`; version-specific and not yet a frozen monolithic standard.                            | [`reference/ncp.md`](reference/ncp.md)       |
| **Plugin**                 | OS subprocess connected over stdin/stdout and participating in NCP. Do not use the term interchangeably with Lua actor or MAG actor.                                                   | [`plugin-authoring.md`](plugin-authoring.md) |
| **Ready / ready OK**       | NCP system request and direct acceptance reply that enter a subprocess into the ready set.                                                                                             | [`reference/ncp.md`](reference/ncp.md)       |
| **Run context**            | Per-`mag.execute` inventory, routing, firing, correlation, and observer state isolated from concurrent MAG runs. It is a kernel implementation concept.                                | `plugins/mag/docs/ir.md`                     |
| **Runner**                 | Engine subsystem that resolves commands, starts subprocesses directly, and bridges stdio.                                                                                              | `engine/src/ncp/runner.rs`                   |
| **System message**         | NCP framework traffic such as `ready`, `ready_ok`, and direct errors, as opposed to plugin event speech.                                                                               | [`reference/ncp.md`](reference/ncp.md)       |

Hello, goodbye, heartbeat, manifest, request IDs, and advisory `body.to` are plugin ecosystem conventions, not core protocol primitives.
